
# Python Mini Projects

A collection of beginner-friendly Python mini projects created to practice Python programming concepts.

## Projects

### 1. Temperature Converter

A Python program that converts temperatures between Celsius, Fahrenheit, and Kelvin.

**Features:**
- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Celsius to Kelvin
- Kelvin to Celsius
- Fahrenheit to Kelvin
- Kelvin to Fahrenheit

**How to Run:**
```bash
python temperature_converter.py
```

### 2. Quiz Game

A simple Python quiz game that asks multiple-choice questions and keeps track of the player's score.

**Features:**
- Multiple-choice questions
- Score tracking
- User input
- Displays the final score

**How to Run:**
```bash
python quiz_game.py
```

### 3. Password Generator

A Python-based password generator that creates random passwords based on the character types selected by the user.

**Features:**
- Custom password length
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Input validation
- Ensures selected character types are included
- Copies the generated password to the clipboard

**How to Run:**
```bash
python password_generator.py
```

### 4. File Word Counter

A Python program that reads a text file and analyzes its contents by counting words, lines, characters, and alphabets.

**Features:**
- Counts total words
- Counts total lines
- Counts total characters
- Counts total alphabets
- Calculates word frequency
- Identifies the most frequently occurring word(s)
- Handles empty files and missing files

**How to Run:**
```bash
python file_word_counter.py
```
